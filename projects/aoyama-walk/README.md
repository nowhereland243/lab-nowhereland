# Aoyama Walk

An immersive, scroll-based walking map of Aoyama, Tokyo.

## About

A minimalist guide to an afternoon walk through Aoyama's fashion and cultural landmarks. The experience combines Japanese Sumi-e ink wash aesthetics with modern web interactions.

## Route

1. **tonkatsu.jp** - Omotesando
2. **Nezu Museum** - Art & Garden
3. **Yohji Yamamoto** - Avant-Garde Fashion
4. **Comme des Garçons** - Rei Kawakubo
5. **Issey Miyake** - Homme Plissé

## Features

- Scroll-based storytelling
- Location-specific imagery
- Minimalist Sumi-e aesthetic
- Mobile-optimized experience
- Interactive map with smooth transitions

## Tech

- Pure HTML/CSS/JavaScript
- No frameworks
- Responsive design
- Optimized for mobile
